## hson-live 3.5.0

This release significantly expands the Hson runtime model, adds exact SSR/continuation, introduces new exact value types, strengthens hosted authority and client replication, and tightens the public API surface.

### New value types

- Added **`HsonData`**, an immutable exact data-context value that preserves canonical ordering and exact semantics without forcing early conversion to ordinary JavaScript objects.
- Added **`HsonDocument`**, an immutable exact document-context value for zero, one, or many top-level document items.
- Closed empty-document handling across parsing, serialization, Schema, LiveMap, SSR, workers, and hosted snapshots.

### Schema

- Added **alphabet refinement**.
- Added public Schema **`any`** support.
- Added **configured relational array uniqueness**, allowing Schema-defined finite overlap/resource constraints such as mutually exclusive Deck cell regions.
- Extended generated TypeScript evidence and editor/runtime validation for these features.

### LiveMap

- Integrated exact `HsonData` handling into data and action flows.
- Added **canonical interactions**, allowing portable event descriptors to live in canonical state while actual JavaScript behavior remains in runtime capability tables.
- Added Libraries snapshot installation and Libraries SSR support.
- Tightened the public QUID boundary: paths remain the normal address model; raw-QUID mutation targeting and manual `ensureQuid`-style APIs were removed from the intended public surface.
- Removed the browser-specific LiveMap compatibility facade; `hson.liveMap` now points to the canonical LiveMap facade.

### LiveTree

- Added **non-destructive grafting**.
- Reworked listener registration and cleanup semantics.
- Decoupled runtime resource lifetime from QUID ownership.
- Repaired hosted form-state realization.
- Added **`AsyncLiveTree`** for authority-backed asynchronous authoring.
- Narrowed the public CSS/runtime implementation surface.

### Mirror

- Renamed the public Reflect subsystem to **Mirror**:
  - `hson-live/reflect` → `hson-live/mirror`
  - `hsonReflect` → `hsonMirror`
  - `DocumentReflect` → `DocumentMirror`
  - related status/error types renamed accordingly
- Preserved grammatical reflection APIs such as `reflect_document()` and `hson.reflect(...)`.

### Locus and Echo

- Hardened external action admission, authorization, deduplication, request lineage, recovery fencing, and session lifecycle.
- Refactored Echo into a more **transport-neutral, lazily loaded capability model**.
- Added transport-neutral operation support beyond a WebSocket-specific internal shape.
- Exposed exact Locus client message encoding for specialist/custom peers.
- Normalized Locus public methods to camelCase.
- Removed legacy synchronization-manager surfaces.

### SSR and continuation

This is one of the largest additions in 3.5.

- Added **exact document continuation**:
  - `continue_document`
  - `continue_hosted_document`
- Added parser-stable browser realization that is distinct from Hson’s ordinary HTML transport serialization.
- Added **same-revision SSR** for local rendering and hosted document state:
  - `render_document`
  - `render_hosted_document`
- Added Libraries SSR.
- Added deterministic, exact SSR bootstrap encoding/decoding:
  - `encode_ssr_bootstrap`
  - `decode_ssr_bootstrap`
- Added bootstrap size/memory limits.
- Continuation adopts existing DOM rather than rebuilding it.

### LiveHost / LiveHost Node

- Added **HTTP/2 support with HTTP/1 fallback** to LiveHost Node.
- Standardized terminology around **LiveHost Node** / **LiveHost Node runtime**.

### VS Code extension

- Added Hson syntax highlighting in Markdown fenced code blocks.
- Added a local application runner that can launch a real workspace Hson application under the workspace’s own Node runtime and installed `hson-live`.
- Added local app lifecycle controls, runtime/version validation, process isolation, loopback hosting, and package/source-authority checks.

### Public API cleanup

- Significantly narrowed and curated the root package exports.
- Added/standardized specialist entrypoints including:
  - `/hson`
  - `/transform`
  - `/livemap`
  - `/livetree`
  - `/mirror`
  - `/locus`
  - `/echo`
  - `/ssr`
  - `/livehost`
  - Node-specific subpaths
- Removed:
  - `hson-live/types`
  - `hson-live/diagnostics/test-exports`
  - `hson-live/reflect`
- Removed or narrowed a large amount of implementation/internal surface from root exports.

### Transform

- Removed the old output-sanitizer compatibility surface.
- Trust is now expressed at ingress through:
  - `fromTrustedHtml`
  - `fromUntrustedHtml`
- Removed `sanitizeBEWARE`.
- Replaced leaked internal output-constructor typing with `TransformOutput`.

### Licensing

- Changed from **Parity Public License 7.0.0** to **PolyForm Strict License 1.0.0**.

This is a material licensing change, not metadata cleanup.

### Breaking changes

Downstream consumers may need to update for:

- `/reflect` → `/mirror`
- `hsonReflect` → `hsonMirror`
- `DocumentReflect*` → `DocumentMirror*`
- removal of `hson-live/types`
- removal of broad root exports
- snake_case → camelCase Locus methods
- action payloads/results using exact `HsonData`
- removal of Transform sanitizer compatibility APIs
- tightened QUID/public document targeting
- narrowed LiveTree CSS implementation exposure
- removal of the browser LiveMap compatibility facade
- new license terms
