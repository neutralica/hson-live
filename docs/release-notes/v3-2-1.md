## 3.2.1 — 2026-07-30

hson-live 3.2.1 tightens canonical ordering and ingress behavior, replaces the
LiveProject subsystem with Reflect, restores reversible markup attribute
handling, and reconciles Element and QUID lifecycle contracts before the
Transform torment-testing campaign.

### Compatibility notes

- Renamed the LiveProject subsystem to Reflect.
- Replaced the former LiveProject APIs and entrypoint with:
  - `hsonReflect(map)`
  - `hsonReflect.collection(options)`
  - `Reflect`
  - `DocumentReflect`
  - `CollectionReflect`
  - `hson-live/reflect`
- Removed LiveProject aliases, compatibility exports, paths, diagnostics, error
  names, and generated declarations.
- `_hson_ii.$_meta.index` now requires exact dense zero-based positional string
  values.
- Valid wrapper permutations are reordered during admission; malformed,
  duplicate, missing, gapped, or out-of-range index sets reject.
- Metadata on `_hson_root` now rejects instead of being silently filtered.
- Invalid ordinary attribute names and authored private parser-transit names now
  reject instead of being renamed or discarded.

### Canonical array ordering

- Established `$_meta.index` as required canonical ordering metadata for
  `_hson_ii` wrappers.
- Kept index values string-valued.
- Made wrapper indexes exact canonical decimal strings matching their physical
  zero-based positions.
- Canonicalized valid wrapper permutations during admission without mutating
  caller input.
- Rejected missing, malformed, duplicate, noncontiguous, noncanonical, and
  out-of-range index values.
- Removed LiveMap numeric index parsing, sorting, compaction, and silent item
  omission.
- Aligned Transform, LiveMap, paths, equality, replay, recovery, snapshots, and
  exact codecs on canonical physical array order.
- Preserved intrinsic JSON and HSON array order as the source of generated
  positional indexes.

### Reversible ordinary-attribute transport

- Replaced the former sidecar attrmap and suffix-based XML mangling mechanism
  with deterministic self-decoding private transit names.
- Restored canonical-valid colonized ordinary attribute names after XML parser
  transit.
- Prevented private parser spellings from entering canonical graph state or
  serialized output.
- Rejected invalid ordinary attribute names before transit encoding.
- Rejected authored, malformed, undecodable, colliding, and case-equivalent
  private transit names at canonical boundaries.
- Returned `data--attrmap` fully to ordinary application data.
- Preserved distinct names such as `a:b` and `a__COLON__b` without conflation.
- Aligned browser, Worker, direct Element, and SVG attribute admission.
- Unified nested SVG handling, including deterministic `href` and `xlink:href`
  precedence.

### Duplicate attribute handling

- Applied duplicate policy while original semantic source names are still
  available.
- Made ordinary duplicate attributes use the final encountered value.
- Made duplicate `class` attributes merge unique tokens in encounter order.
- Prevented duplicate attributes from becoming invented suffixed canonical
  names.
- Made duplicate and case-equivalent HSON metadata declarations reject.
- Preserved the explicit limitation that direct Element input begins after the
  DOM has already collapsed lexical duplicates.

### Browser and Worker sanitizer parity

- Separated security sanitization from canonical metadata validation.
- Preserved syntactic `hson:*` candidates through browser and Worker sanitizers
  for exact registry admission.
- Made malformed, unknown, misplaced, duplicate, and private metadata reject
  consistently across environments.
- Preserved valid supplied QUIDs through untrusted HTML ingestion.
- Kept QUID identity separate from trust, authorization, and authentication.
- Preserved ordinary `data-*`, including `data-_quid`, `data-_index`, and
  `data--attrmap`, as application attributes.
- Removed unsafe event attributes without silently removing valid HSON
  identity.
- Preserved ordinary admitted text while continuing to remove hard-forbidden
  elements and content.
- Added browser and Worker support for sanitized XML-shaped array wrappers.
- Added real-browser coverage through the production untrusted-HTML API.

### Strict, detached JSON ingestion

- Removed stale JSON root-metadata filtering.
- Made populated or malformed `_hson_root.$_meta` reject through shared
  canonical validation.
- Kept absent, `undefined`, and empty optional metadata records neutral under
  the established optional-record policy.
- Made root `$_meta: []` reject instead of using the legacy permissive
  empty-array spelling.
- Recursively detached parsed JSON values before normalization.
- Prevented successful and rejected JSON parsing from mutating caller-owned
  arrays, records, attributes, styles, metadata, or nested values.
- Prevented returned canonical graphs from retaining mutable aliases into
  caller input.
- Copied shared acyclic references by value.
- Rejected cycles and unsupported non-plain objects deterministically.
- Preserved direct JavaScript negative zero while retaining native JSON text
  semantics.
- Kept exact versioned graph codecs separate from projected JSON ingestion.

### Reflect

- Renamed LiveProject to Reflect throughout source, tests, entrypoints,
  declarations, diagnostics, errors, synchronization states, counters, and
  documentation.
- Added callable `hsonReflect(map)`.
- Added `hsonReflect.collection(options)`.
- Added the `hson-live/reflect` public entrypoint.
- Added canonical `Reflect`, `DocumentReflect`, and `CollectionReflect` type
  families.
- Renamed collection synchronization from `resync()` to `synchronize()`.
- Preserved LiveMap as the sole canonical state authority.
- Defined Reflect as an optional projection and reconciliation layer between
  LiveMap authority and LiveTree projection resources.
- Removed all LiveProject and LiveProjection compatibility terminology and
  exports.

### Element and QUID contracts

- Defined direct HTML, XML-shaped, and SVG Element input as representing the
  supplied element itself as the source root.
- Distinguished direct Element admission from the intentionally child-only
  Transform `queryDOM()` and `queryBody()` snapshot helpers.
- Preserved root and descendant attributes, metadata, QUIDs, and content during
  direct Element admission.
- Documented DOM-boundary limitations involving duplicate attributes, casing,
  namespaces, quoting, whitespace, and lexical source spelling.
- Preserved valid supplied QUIDs across trusted, untrusted, Worker, HSON, JSON,
  raw-node, HTML Element, SVG string, and SVG Element ingress.
- Kept cold graph QUID validation separate from active runtime ownership.
- Preserved cold duplicate-QUID behavior while enforcing active same-runtime
  uniqueness atomically.
- Confirmed equal QUIDs remain legal in separate runtimes.
- Confirmed detach, movement, and reattachment retain identity.
- Confirmed clones receive fresh QUIDs.
- Confirmed terminal destruction releases active identity and projection
  resources.
- Confirmed `.noQuid()` filters output without mutating graph identity or
  runtime ownership.

### Dead-code removal

- Removed the unreachable legacy `construct_tree()` construction engine.
- Removed obsolete graft and constructor types associated with the old path.
- Added source, declaration, artifact, and public-export checks preventing the
  obsolete construction engine from returning.
- Removed stale `innerHTML`, descendant-QUID stripping, and parser-time reminting
  descriptions from current contracts.

### Test architecture and diagnostics

- Assigned managed CSS state, CSSOM, ownership, scheduling, replacement, and
  cleanup assertions to synthetic DOM tests.
- Assigned rendered selector behavior and computed-style application to real
  Chromium tests.
- Removed all executable synthetic `getComputedStyle()` assertions.
- Added real-browser coverage for HTML and SVG QUID targeting, flush boundaries,
  replacement, cleanup, root isolation, stable identity, and pseudo-element
  content.
- Reclassified pseudo-selector tests according to the behavior their
  environments can prove.
- Expanded canonical, external, Worker, browser, hosted, and inclusive test
  inventories.
- Improved hosted discovery validation with Reflect subject support and
  indexed field-level diagnostics.
- Preserved exact launcher completion, manifest, and inventory truthfulness.

### Documentation
