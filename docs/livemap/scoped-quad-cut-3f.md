# Scoped QUAD Cut 3F: private initial restoration

Cut 3F connects the existing scoped document representation to selected Locus
capture and complete Echo client composition. It does not enable public hosted
delivery, checkpoints, browser continuation, or chained `.q()`.

Authored initial Part expansion retains `candidate.scoped` through the canonical
Library candidate as `compositionScopes`. Initial installation uses the existing
scoped composition issuer and stylesheet owner to install the realized graph,
namespaces, occurrence lifetimes, subject overlay, and CSS together. Canonical
graph nodes still contain no authored QUAD declarations. Legacy flattened inputs
remain flat; missing occurrence evidence is never recovered from their graphs.

The private opt-in on `capture_selected_authority_projection_snapshot` extends
each existing document entry with `scopes`. The existing encoded `root` and `css`
plus that field are exactly the `PortableDocumentScopedLibrary` semantic value.
There is no second root, stylesheet, snapshot family, version, or authority
counter. The scope codec owns topology, local names, and disposable CSS subject
correspondence. Scope content participates in the state fingerprint, not in the
Schema or authorized Library contract. An entry cannot contain both `scopes`
and flat `quads`; absent scopes retain the established flat contract, while an
explicit empty scope record is a complete scoped document.

`create_echo_scoped_replica_internal` admits one complete authorized projection
before constructing its receiving map. It uses the existing client composition
adapter, registry authority, scoped decoder, sparse issuer, and CSS translator.
All projected documents, data Libraries, and shared interactions arrive together.
Private Parts and unselected Libraries are unnecessary. Subject transport labels
are excluded from allocation across the entire candidate and never become lookup
aliases or receiving identity authority.

The capability's `restoreScopedProjection` replaces the projected partition using
the existing atomic restoration candidate. It preserves client-local Libraries
and descriptors. Full scoped restoration always creates fresh receiving identities
and occurrence lifetimes, including for graph-identical input. Flat restoration
retains its prior continuity behavior. Only the current logical map, incarnation,
projection contract, and projected registry are admitted; revisions cannot move
backward. These are private reconstruction primitives, not recovery orchestration.

Restoration captures the authentic management grant before inspecting caller
input. Admission produces an owned immutable projection, used consistently for
content and authorization. Grant lifetime, transition generation, identity state,
and authority position are checked through preparation and immediately before
installation, including equivalent acceptance. Identities are staged in the
existing candidate ledger. Rejection publishes nothing and does not undo work
accepted reentrantly under a replacement grant.

The default selected capture, session-now admission, public Echo preparation,
ordinary cuts, checkpoints, and SSR guards remain closed to explicit scoped
state. Initial authored Part documents now reach those guards because their
scoped evidence is retained. Existing flat rendering, cut, CSS, and checkpoint
coverage uses explicitly flat fixtures; it does not claim scoped support.

This intentionally withdraws the incomplete pre-epoch public hosted styled-Part
SSR behavior, which delivered a flattened graph without its occurrence evidence.
For scoped documents, public `session.now()` (with or without HTML), cuts, and
SSR capture reject until coordinated Cut 3H activation. Scoped hosted snapshots,
browser SSR bootstrap, and public Echo reconstruction cannot safely reuse the
old flat contract. Ordinary flat authored QUAD documents retain public capture,
first-paint CSS/subject correspondence, bootstrap, and Echo reconstruction support.

Cut 3G must integrate this complete per-document value with the existing durable
checkpoint/tail owners and their recovery fences, without persisting runtime
QUIDs, ledgers, epochs, or occurrence objects. Cut 3H must coordinate session,
network, projection/reconciliation, and receiving admission before enabling public
delivery. Neither cut may erase scope evidence to use a flat path. SSR and browser
continuation must eventually carry/adopt these explicit boundaries and translate
subject correspondence under their receiving identity authority; graph equality
or disposable labels cannot prove continuity.

Permanent acceptance: `npm run test:echo-scoped-initial-state` runs the same cases
in Node and an actual `worker_threads.Worker`, including fresh receiving maps,
ordered Cut 3E replay, malformed multi-Library candidates, allocation failure,
management replacement, and closed public admission.
